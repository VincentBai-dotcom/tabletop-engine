---
title: "tvk upload"
description: "Upload engine and frontend source and start a Tableverse build."
---

`tvk upload` packages both source trees from `tableverse.config.ts`, uploads them, and starts a Tableverse build.

It does not build either package on your machine.

## Before the first upload

Make sure your config has a `publish` block and your project has a lockfile:

```bash
pnpm typecheck
pnpm exec tvk validate
pnpm exec tvk login
```

Check the active account at any time:

```bash
pnpm exec tvk whoami
```

## Upload

```bash
pnpm exec tvk upload
```

For an unlinked project, the CLI asks you to create a game or choose one already in your account. It then writes the selected ID to:

```text
.tableverse/game.json
```

Future uploads use that link. The CLI prints the target game name and ID before packaging.

<Warning>
  A copied project may retain `.tableverse/game.json`. Verify the printed target before uploading so you do not publish over another game.
</Warning>

## What gets uploaded

The CLI uploads source from `publish.engine.root` and `publish.frontend.root`.

It excludes:

- `node_modules`, `.git`, and `.tableverse` directories.
- The frontend `outDir` because Tableverse rebuilds it.
- Local `.env` files such as `.env.local`.
- Symbolic links.

Files such as `.env.example` remain included. Packaging stops if it finds common private-key or credential files, including `.npmrc`, `.pem`, and `.key` files.

Each configured source root must contain a recognized package-manager lockfile.

## Follow the deployment

After both uploads finish, the CLI starts the build and prints a dashboard URL. In an interactive terminal, it also tries to open the page in your browser.

The dashboard shows the platform build of:

- The engine source into the hosted rules bundle.
- The frontend source using `frontend.buildCommand`.
- The static files served from `frontend.outDir`.

## Upload from CI

An unlinked non-interactive job cannot answer the first-run prompt. Set the game explicitly:

```bash
TABLEVERSE_GAME_ID=game_123 pnpm exec tvk upload
```

`TABLEVERSE_GAME_ID` overrides the saved project link. Authentication must already be available for the same platform API environment.

## Use a different config

```bash
pnpm exec tvk upload --config configs/production.tableverse.config.ts
```
