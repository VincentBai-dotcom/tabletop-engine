The `tvk` command runs your game locally and hands finished source to Tableverse. The scaffold installs it in the project root.

From the project root, invoke it with:

```bash
pnpm exec tvk --help
```

## Commands

| Command | Purpose |
| --- | --- |
| `tvk validate` | Load and validate the game definition. |
| `tvk dev` | Start the local rules server and frontend. |
| `tvk login` | Sign in to Tableverse in your browser. |
| `tvk whoami` | Print the signed-in account. |
| `tvk logout` | Revoke and remove the saved login. |
| `tvk upload` | Package engine and frontend source and start a platform build. |

Use `--help` after any command to see its current options:

```bash
pnpm exec tvk upload --help
```

## Config file

`tvk validate`, `tvk dev`, and `tvk upload` load `tableverse.config.ts` from the current working directory by default.

```ts
import { defineConfig } from "@tableverse-kit/config";
import { game } from "./engine/src/game.ts";

export default defineConfig({
  game,
  publish: {
    engine: { root: "./engine" },
    frontend: {
      root: "./client",
      buildCommand: "pnpm build",
      outDir: "dist",
    },
  },
});
```

Pass a different path with `--config`:

```bash
pnpm exec tvk validate --config configs/demo.tableverse.config.ts
```

## Recommended checks

Run TypeScript before CLI validation. The CLI loads the built definition, while TypeScript catches mistakes in code paths that may not run during definition assembly.

```bash
pnpm typecheck
pnpm exec tvk validate
```
