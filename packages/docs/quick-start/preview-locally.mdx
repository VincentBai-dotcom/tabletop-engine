---
title: "Preview locally"
description: "Run your rules locally and connect your frontend."
---

Start the rules server and frontend:

```bash
npm run dev
```

`npm run dev` loads `tableverse.config.ts`, starts the rules server at `http://localhost:5100`, and runs the frontend's `dev` script from `publish.frontend.root`.

The scaffold creates one client for local previews and published games:

```ts
import { createTableverseClient } from "@tableverse-kit/client";
import type { executor } from "token-race-engine";

type Game = typeof executor;

const client = createTableverseClient<Game>();
```

During a local preview, the client connects to `http://localhost:5100`. It initializes one in-memory session, receives a player-safe view, and updates all connected browser windows after an accepted command.

## Try multiple players

The first connection initializes the session, so give it the full roster. Other browsers pick a different `viewer` from that roster:

```ts
// First browser — initializes the match
createTableverseClient<Game>({
  viewer: "p1",
  players: ["p1", "p2"],
});

// Second browser — same match, different viewer
createTableverseClient<Game>({
  viewer: "p2",
});
```

If your game defines setup input, pass it from the first client too:

```ts
const client = createTableverseClient<Game>({
  viewer: "p1",
  players: ["p1", "p2"],
  setupInput: { targetScore: 10 },
});
```

<Note>
  The local server keeps state in memory. Restarting `tvk dev` starts a new session.
</Note>

## Change the port

```bash
npx tvk dev --port 5200
```

Pass the same URL when you create the client:

```ts
const client = createTableverseClient<Game>({
  serverUrl: "http://localhost:5200",
});
```
